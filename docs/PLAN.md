# 通用桌面底座 · 2026-10-18

## 交付范围

独立目录 ai-desktop，产品暂名 Desktop Starter。基于 credit-ui 的字体、主题、基础组件，用 Electron + TypeScript 提供 Windows 桌面运行与打包。无聊天、模型、账户、积分、支付、项目管理等业务。

- 概览、交互组件、设置、关于；可收起导航与应用内快捷键。
- 明暗/跟随系统、原配色主题、减少动态效果，偏好持久化。
- 系统目录选择（只返回选择结果）、应用信息、打开应用数据目录、固定文档链接。
- 一体式 Credit 风格标题栏与原生窗口按钮；恢复窗口大小、位置及最大化状态；单实例。
- 居中 Logo 呼吸启动画面；初始化就绪即进入应用，失败可重试，遵循减少动态效果设置。
- 隔离 renderer / preload / main。仅暴露明确方法；校验 IPC 来源和参数；禁止任意外链、页面导航及未授权浏览器权限。
- 静态资源内置，通过 app://desktop 提供，无生产本地 HTTP 服务。

## 验证顺序

1. 先写偏好、静态路径、IPC 来源/外链策略测试，观察失败。
2. 实现通用内核，再完成桌面界面；运行单测、类型检查、构建。
3. 使用 Playwright Electron 对真实 Electron 窗口测试导航、主题、持久化、窗口状态与桥接安全；查看截图。
4. 独立代码审查；修复实际问题。生成 Windows 安装包，验证打包产物的运行。

## 后续扩展位置

shared/contracts.ts 是 renderer/preload/main 的契约；desktop/ 放受控系统能力；components/desktop-shell.tsx 是页面壳。后续业务挂在壳内，不扩大通用 IPC 到任意文件读写或命令执行。

## 第一批成熟度能力（0.2.0）

- 本地轮转日志、白名单诊断 JSON、凭据与路径过滤、导出失败反馈；不上传，不采集业务文本。
- 原生进程故障恢复、20 秒白屏监测、React 恢复页与致命异常退出；全部由用户选择，不做自动循环。
- 固定 release/current 安装包与快捷方式入口；原有 userData/appId 不变。历史 EXE 保留但退出使用。
- 验收：单测/类型/构建；真实 Electron 故障注入与现有烟测；独立审查；安装包生成后，对同一解包产物再次验收。安装/卸载和签名不代替人工确认。

## 第二批成熟度能力（0.3.0）

- 设置管理：64 KiB 上限、严格白名单/版本的 JSON 外观备份，取消不改，失败不部分应用；重置需确认并保留窗口/OS 启动项。
- Ctrl/⌘+K 快捷操作，搜索、方向键、Enter、Escape；保留现有快捷键和一体式标题栏。
- 托盘和 Windows 安装版登录启动均默认关闭；用户明确开启才驻留/注册。托盘退出绕过隐藏路径，登录选项读取系统实际状态。
- 固定 GitHub Releases 源 haipengTian/normal-desk；显式检查、下载进度、确认安装、错误重试。校验由 electron-updater 保留执行；安装器启动成功再退出，失败保持客户端并允许重试。
- 仅本地构建，不初始化 Git、推送或发布。准备标签触发的 Windows 草稿发布 workflow，版本与 tag 一致；用户检查草稿后发布。
- 验收：单测/类型/构建、真实客户端第二批烟测、loopback 真下载与损坏校验、独立审查及修复、最终解包产物烟测/稳定性。正式 GitHub 更新与安装/签名验收依赖后续发布，分别记录。

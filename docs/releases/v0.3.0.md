# Desktop Starter v0.3.0

基于 Credit UI 的通用 Windows 桌面客户端底座，无聊天或账户等业务。

## 新增

- 设置导入、导出与确认恢复默认；备份仅包含外观和交互偏好。
- `Ctrl+K` 快捷操作，支持搜索、方向键、回车与 Escape。
- 可选托盘驻留与登录系统时启动，默认均关闭。
- GitHub Releases 更新：手动检查、下载进度、确认重启安装、失败重试。

## 安装

下载 `Desktop-Starter-Setup.exe`。关闭旧版后运行安装包，后续从桌面或开始菜单的 Desktop Starter 启动。

这是首个 GitHub 发布版本。0.2.0 及更早版本需手动安装这次更新；0.3.0 后可在“关于 → 应用更新”检查更高版本。

当前为未签名测试构建，Windows 可能显示未知发布者或 SmartScreen 提示。完整跨版本安装升级仍待后续版本验收；此版不支持 macOS/Linux。
